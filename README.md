### A Discrete-Event Simulator for Adaptive Data-Center Resource Allocation
_**Orchestrix**_ is a C++ project developed for our Semester 3 Object-Oriented Programming with C++ course.

It simulates job scheduling and resource allocation across data center servers with varying CPU, RAM, storage, and GPU capacities.

### Features
- **Three scheduling strategies:** First Fit, Best Fit, and Load Balanced.
- **Discrete-event simulation:** Models job arrivals, execution, completion, and resource release.
- **Resource management:** Tracks server capacities and prevents over-allocation.
- **Performance metrics:** Measures waiting time, throughput, job outcomes, and resource utilization.
- **Strategy comparison:** Evaluates scheduling strategies on equivalent workloads.
- **Automated testing:** 151 tests reported passing across four development milestones.

### Tech Stack
- **Language:** C++17
- **Build System:** CMake
- **Compiler:** GCC
- **Testing:** CTest

### Project Status
CLI, workload generation, and final integration are in progress.
